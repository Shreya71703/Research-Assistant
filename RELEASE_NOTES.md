# Release Notes — AI Research Assistant v1.0.0

We are excited to announce the official **v1.0.0** release of the **AI Research Assistant** platform!

---

## 🌟 Highlights

- **LangGraph Tool Calling Engine**: Autonomous agent state machine routing queries dynamically across 7 integrated research tools.
- **Groq Llama 3.3 70B Integration**: Sub-second LLM inference speed.
- **Real-time SSE Event Streaming**: Streaming `thinking`, `tool_start`, `tool_result`, `response`, and `done` events directly to the client.
- **Full Interactive React 18 SPA**: 9 complete workspace pages including Dashboard telemetry, Research Workspace, Kanban Board, Vector KB, Reports, and Analytics.
- **System-Independent Light & Dark Themes**: Instant theme toggle with local storage persistence.
- **Zero-Cost Production Configurations**: Pre-built configurations for Vercel, Render, Neon PostgreSQL, and Docker.

---

## 📊 Package Dependencies
- React 18, Vite 5, Tailwind CSS 3, shadcn/ui, Framer Motion, Zustand 4, React Router 6.
- FastAPI 0.104, LangGraph 0.2, LangChain Groq 0.2, ChromaDB, Uvicorn, Gunicorn.
